# Zenith-Coderz---NammaCare-Chennai
NammaCare Chennai

Healthcare Made Easier for Everyone

NammaCare Chennai is a healthcare navigation web application developed for the CodeNex Hackathon – The Other Side. It helps people find nearby hospitals and clinics, check availability, explore routes, and access essential healthcare information.

 Features

- Nearby Hospitals: Find hospitals and clinics based on your location.
- Navigation: View routes, distance, and estimated travel time.
- Traffic Updates: Access live traffic information through Waze.
- Accessibility Filters: Check wheelchair accessibility.
- Bilingual Support: Available in English and Tamil.
- OPD Token Booking: Generate demo tokens for hospital visits.
- Emergency Assistance: Quick access to emergency number 108.
- Dark Mode: Comfortable viewing experience.
- Human Navigator: Generate a handoff summary for assistance.

 Technologies Used

- HTML
- CSS
- JavaScript
- Leaflet.js
- OpenStreetMap
- OSRM
- Nominatim
- Waze

🎯 Our Goal

Our goal is to make healthcare navigation simpler, more accessible, and convenient for people in Chennai by helping them locate healthcare facilities and plan their visits.
